# Portfolio Website Implementation Plan

## Objective
Build and deploy a cyberpunk-themed personal portfolio website on GitHub Pages.

## Specs
- **Theme:** Dark, cyberpunk aesthetic (neon accents, terminal-like feel).
- **Typography:** JetBrains Mono font.
- **Content:**
    - **Hero Section:** "Jirat Vice".
    - **Projects:** 3 highlighted projects.
    - **Contact:** Links/email for contact.

## Implementation Steps

### 1. Project Setup
- Initialize repository structure:
    - `index.html` (main entry point)
    - `style.css` (cyberpunk styling)
    - `script.js` (basic interactions)
    - `assets/` (images/icons)

### 2. Frontend Development
- **Structure:** Semantic HTML5 for sections (Hero, Projects, Contact).
- **Styling:**
    - Use CSS variables for a consistent neon color palette.
    - Import JetBrains Mono via Google Fonts.
    - Implement flexbox/grid for responsive layout.
- **Content:** Fill out placeholders with the specified requirements.

### 3. Deployment
- Push files to a GitHub repository.
- Navigate to Settings > Pages to configure the publishing branch.

## Verification
- Test site responsiveness on different screen sizes.
- Verify all links and project cards are functional.
- Confirm live deployment at `username.github.io/<repo>/`.
